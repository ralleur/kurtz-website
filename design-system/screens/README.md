# Canonical screens / Editorial Reference v2

Full-page captures of all six public pages at 390 and 1440 CSS px, viewport
height 900px, DPR 1, Chromium 145 headless. Capture after local fonts and
all images load; use default disclosure states. The site has no autoplay.
`home-*` names refer to the root route. `manifest.json` records dimensions,
compact WebP sizes and hashes. Product pixels are unchanged website assets;
these screenshots document their presentation, not a new license for them.

Recreate after a visual change using the existing local preview, then inspect
all sections at full size before replacing these files. Also inspect 320, 768
and 1920px, open tours, keyboard, 200% text/reflow and reduced motion as required
by the parent reference. Keep full QA logs and comparison photographs outside
the served tree and outside this public repository.
